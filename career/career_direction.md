# Career Direction — 希望職種と対象読者

## 基本肩書き

**Research-oriented Software Engineer** — AI推論基盤・決定論的システムを研究開発するソフトウェアエンジニア。

「研究者」「R&D Engineer」と断定するだけの表現は避け、実装能力と研究開発志向の両方を示す肩書きとして採用している。

## 中心メッセージ

複雑な推論システムの仮説を、仕様、実行可能なソフトウェア、再現可能な実験、検証証拠へ変換する。

## 対象職種(優先順位)

| 優先度 | 対象職種 |
|---|---|
| 1 | AI Systems Engineer / AI基盤エンジニア |
| 2 | Research Software Engineer |
| 3 | QA / Test Automation / Validation Engineer |
| 4 | Developer Tools / Runtime / Compiler関連エンジニア |
| 5 | DX推進 / 社内SE / 業務自動化エンジニア |
| 6 | R&D Engineer / Applied Research Engineer |
| 7 | 技術PM / 導入SE / 技術支援 |

正社員エンジニア職を第一希望とし、副業・業務委託案件についても技術能力と研究開発実績の提示先として本ポートフォリオを利用する。

## 想定する読者

- 技術採用担当者
- エンジニアリングマネージャー
- CTO / 研究開発責任者
- 転職エージェント
- SES / 受託開発企業の技術責任者
- 副業・業務委託案件の発注担当者
- OSS利用者・共同研究候補者

## なぜこのポジショニングか

企業内でのSE職歴は持たない一方、プログラミング教育・カリキュラム設計、システム開発に関連するPM経験、そして約1年7ヶ月にわたる個人研究開発——DSL・AST・IR・Runtime・CLI・Validatorの設計実装、決定性・再現性・監査可能性の検証——という実績を持つ。年齢や「SE未経験」を中心に置くのではなく、**能力と証拠**を優先して提示する方針を取っている。
